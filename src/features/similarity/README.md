# similarity

Family Segmented control, algorithm text buttons, the score strip and the
six-capability result table, the trace panels (DP matrix, TF-IDF, Jaccard,
embeddings) with the result tiles and ranking above them, and the similarity
matrix with its heat legend. Never computes a score — all values come from the
backend; the rank shown is only a reading of the order of `normalizedScore`
among the rows on screen.
